# 코드와 화면의 출처

## 코드

원본은 Zero Soda Agent 로컬 체크아웃의 커밋 `ac2fd3fbd6234a3f61f828bd05b3622113b1b1ff`를 기준으로 발췌했습니다. 이 식별자는 추출 기준이며 현재 운영 릴리스가 아닙니다. 초기 공개본의 대조 기록은 아래 범위를 확인했습니다.

| 공개 파일 | 기존 구현 | 공개용 변경 |
|---|---|---|
| [seller_table.py](../examples/seller_table.py) | `src/zero_soda_agent/danawa.py`의 가격 파싱·표 판정 함수 6개 | 함수 본문과 상수 값을 그대로 발췌. 표준 라이브러리 import·출처 설명 추가. HTTP 수집·HTML 파싱·목적지 조회 제외 |
| [price_evidence.py](../examples/price_evidence.py) | 같은 이름의 원본 모듈 | 전체 파일 바이트 동일 |
| [demo.py](../examples/demo.py) | 원본 수집기의 행별 증거 연결 구조 참고 | 공개본용 연결 코드. 합성 URL 사용, 저장·게시 제외 |
| [scenarios.json](../examples/scenarios.json), [expected.json](../examples/expected.json) | 원본 경계 조건 참고 | 공개본용 합성 입력·기대 결과. 실제 판매처 응답이 아님 |
| [test_price_gate.py](../tests/test_price_gate.py) | 기존 가격 증거 회귀 검사의 기준 참고 | 합성 예제와 공개 경로용 검사. 원본 통합 테스트 전체를 이전한 것은 아님 |

이번 문서 개정에서는 위 코드·샘플·테스트를 수정하지 않았습니다. 최초 추출 시 원본과의 대조와 이번 문서 편집은 별도 작업입니다.

## 화면

README의 `demo-board.png`와 `demo-detail.png`는 `experiment/value-first-repackage` 개발 브랜치를 Vite와 `fixture=value-first` 데이터로 실행한 화면입니다. 원본 파일은 `01-online-first-390x844.png`, `03-online-detail-390x844.png`이며 커밋 `75b7134`의 시각 검증 기록에 포함돼 있습니다. 초기 공개본에서 두 이미지를 변경 없이 복사했습니다.

가격·판매처·행사·갱신 시각은 합성 데이터입니다. 실제 앱 코드의 개발 화면이지만 현재 운영 가격이나 토스 실기기 화면은 아니며, 새로 그린 UI 목업도 아닙니다. README에서 개발 데모임을 표시합니다.

[historical-online.png](../assets/historical-online.png)는 초기 등록 자료의 `01-online-main-636x1048.png`입니다. 기존 등록 자산 문서는 당시 production bundle과 generation 19 API 데이터의 캡처로 기록하고 있습니다. 파일은 2026-08-22 초기 소스 커밋에 존재하나 정확한 촬영 시각은 확인되지 않았습니다. 과거 가격판의 자료이며 현재 UI·가격 상태를 보여주지는 않습니다.

초기 검토 기록상 화면에 개인 계정·고객 피드백·내부 주소는 포함되지 않았습니다. 제품 식별 그림은 프로젝트의 SVG/CSS 도형으로 설명돼 있습니다. 이 저장소에는 별도 폰트 파일·판매처 이미지·제3자 로고 원본을 포함하지 않았습니다. 이번 문서 편집에서는 이미지를 다시 촬영하거나 수정하지 않았습니다.

## 앱 링크

[토스 공유 링크](https://minion.toss.im/9KclBrXp)를 사용합니다. PC에서는 QR을 휴대폰으로 스캔하고, 모바일에서는 링크를 누릅니다.

`assets/open-in-toss.png`는 같은 주소를 QR로 인코딩한 이미지입니다. 초기 공개본에서는 QR을 다시 판독해 주소가 일치함을 확인했습니다. 실기기에서의 앱 실행과 현재 출시 상태는 별도 확인 대상입니다.

## 역할과 AI 협업

기획·제품 판단·검토·운영을 맡았고, 구현은 AI 코딩 도구와 협업했습니다. 첫 화면의 대표 상품, 설정에서 다른 음료를 추가하는 방식, 맛 구분과 용량 선택 범위는 직접 정한 요구입니다. 이를 데이터 모델이나 가격 검증 알고리즘 전체의 독자 설계로 확대하지 않습니다.

공개용 함수 추출, 합성 데이터, 예제 연결 코드, 테스트와 최초 문서 초안은 Codex가 작성했습니다. 이번 문서 개정에도 AI 도구를 활용했습니다. 원본 함수별 최초 제안·작성자는 별도로 확인하지 않았습니다.

## 권리와 범위

발췌한 원본 함수의 주석·docstring은 유지했습니다. 초기 추출 대상에서는 별도 제3자 저작권 고지나 프로젝트 라이선스 파일을 발견하지 못했습니다. 이는 모든 권리 관계를 확인했다는 뜻은 아닙니다. 이 저장소에 새 오픈소스 라이선스를 부여하지 않았으며, 제품명·상표의 권리는 해당 권리자에게 있습니다.
