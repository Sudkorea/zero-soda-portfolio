# 출처와 공개용 변경

## 코드

추출 기준은 기존 Zero Soda Agent 로컬 체크아웃의 커밋 `ac2fd3fbd6234a3f61f828bd05b3622113b1b1ff`다. 추출 파일이 해당 커밋과 같은지 확인했다. 이 식별자는 추출 기준이며 현재 운영 릴리스를 뜻하지 않는다.

| 공개 파일 | 기존 구현 | 공개용 변경 |
|---|---|---|
| [seller_table.py](../examples/seller_table.py) | `src/zero_soda_agent/danawa.py`의 가격 파싱·표 판정 함수 6개 | 함수 본문과 상수 값을 그대로 발췌. 필요한 표준 라이브러리 import와 출처 설명만 추가. HTTP 수집·HTML 파싱·목적지 조회 제외 |
| [price_evidence.py](../examples/price_evidence.py) | 같은 이름의 원본 모듈 | 파일 전체 바이트 동일 |
| [demo.py](../examples/demo.py) | 원본 수집기의 행별 증거 조립 구조 참고 | 이번 공개본의 새 연결 코드. 네트워크 목적지 해석 대신 합성 URL 사용. 저장·게시 제거 |
| [scenarios.json](../examples/scenarios.json), [expected.json](../examples/expected.json) | 원본 경계 조건을 참고 | 이번에 만든 합성 데이터와 명시적 기대 결과. 실제 판매처 응답 복사 아님 |
| [test_price_gate.py](../tests/test_price_gate.py) | 기존 가격 증거 회귀 검사의 판단 기준 참고 | 합성 예제와 공개 경로를 위한 새 검사. 원본 통합 테스트 전체를 이전하지 않음 |

원본 함수의 주석·docstring은 유지했다. 추출 대상에서 별도 제3자 저작권 고지나 프로젝트 라이선스 파일은 발견하지 못했다. 이것이 모든 권리 관계를 증명하지는 않으며, 이 공개 후보에 새 오픈소스 라이선스를 부여하지 않았다. 제품명과 상표의 권리는 해당 권리자에게 있다.

## 화면

README의 `demo-board.png`와 `demo-detail.png`는 기존 `experiment/value-first-repackage` 개발 브랜치에서 Vite와 `fixture=value-first` 데이터로 실행해 캡처한 화면이다. 원본 파일은 각각 `01-online-first-390x844.png`, `03-online-detail-390x844.png`이며 커밋 `75b7134`의 시각 검증 기록에 포함되어 있다. 두 파일은 변경 없이 복사했다.

해당 캡처의 출처 문서는 가격·판매처·행사·갱신 시각이 모두 합성 데이터라고 명시한다. 실제 앱 코드의 개발 화면이며 현재 운영 가격이나 실기기 토스 화면은 아니다. 새로 그린 UI 목업도 아니다. 화면의 상품·판매처명은 예제 식별 텍스트이며 원격 로고·상품 사진·개인 계정 화면은 포함하지 않았다. README에서 데모임을 표시한다.

### 보존한 초기 캡처

[historical-online.png](../assets/historical-online.png)는 기존 등록 자료의 `01-online-main-636x1048.png`를 변경 없이 선별한 것이다. 프로젝트 등록 자산 출처 문서는 production bundle과 당시 generation 19 API 데이터의 실제 캡처라고 기록한다. 파일은 2026-08-22 초기 소스 커밋에 이미 존재하며 정확한 촬영 시각은 확인하지 않았다.

이미지는 과거 가격판의 구현 증거일 뿐 현재 UI·가격·배포 상태의 증거가 아니다. 원본을 시각적으로 확인했으며 개인 계정, 고객 피드백, 내부 주소, 브라우저 주소창이 없는 가격판이다. 기존 출처 문서에 따르면 제품 식별 그림은 원격 로고·사진을 내려받은 것이 아니라 프로젝트의 SVG/CSS 도형이다. 이번 공개본에는 폰트 파일·판매처 이미지·제3자 로고 원본을 포함하지 않았다.

## 앱 연결 정보

프로젝트 소유자가 2026-09-17 제공한 [토스 공유 주소](https://minion.toss.im/9KclBrXp)를 사용한다. PC에서는 QR을 휴대폰 카메라로 스캔하고, 모바일에서는 같은 주소의 링크를 누르는 동선이다.

`assets/open-in-toss.png`는 이 주소를 로컬 QR 도구로 인코딩한 이미지다. 생성 후 QR을 다시 판독해 주소 일치를 확인했다. QR 판독 검사는 실기기에서 토스 앱이 실행되는지 또는 현재 출시 상태가 어떤지를 검증한 것은 아니다. 이번 작업에서는 앱에 접속하거나 운영 API를 호출하지 않았다.

## 기여

역할 설명은 프로젝트 소유자가 이번 작업에서 명시한 기획·문제 정의·제품 판단·검토·운영 범위를 따른다. Git 작성자 필드는 실제 타이핑 주체나 독자 설계의 근거로 사용하지 않았다. AI 코딩 도구와 협업한 구현이며, 특정 알고리즘의 최초 제안자를 추정하지 않았다.

이번 공개용 함수 추출, 합성 데이터, 예제 어댑터, 검사와 문서 초안은 Codex가 작성했다. 개별 원본 함수의 최초 작성자를 확인하지 않았으며, 공개본에서 인간의 단독 알고리즘 설계로 귀속하지 않는다.
