# 로컬 검증 기록

검증일: 2026-09-17. 대상: 이 폴더의 공개 예제. 운영 환경은 검증 대상이 아니다.

## 실행과 기대 결과

README의 두 명령으로 데모와 회귀 검사를 실행했다. 합성 시나리오 8개의 출력은 `expected.json`과 일치했고, `unittest` 검사 메서드 4개가 통과했다. 이 개수는 확인 범위이며 프로젝트 성과나 전체 테스트 수가 아니다.

| 입력 상황 | 가격 증거 게이트 결과 |
|---|---|
| 완전한 표: A 12,000+3,000원, B 16,000+0원 | A·B 모두 통과; 순위 선택은 후속 경로 |
| A 합계 15,000원, 미확인 B 상품가 16,000원 | A만 통과 |
| 미확인 B 하한 15,000원 | 통과 없음 |
| 미확인 B 하한 14,000원 | 통과 없음 |
| 정확한 조건부 배송 표식 | 조건부 행 보존, A만 통과 |
| 표식이 소문자 `y` | 통과 없음 |
| 같은 판매처·옵션의 가격 충돌 | 통과 없음 |
| 상품가+배송비와 보고 합계 불일치 | 통과 없음 |

추가 검사는 배송비 누락·음수, 상품가 0, 금액 불일치, 판매처명 없음, 다른 출처, 목적지 불일치, 깨진 증거 금액, 충돌 표식, 별도 미확인 행, 빈 표와 중복 행을 다룬다.

## 격리와 파일 검토

공개 파일만 임시 디렉터리에 복사해 별도 Python 프로세스로 재실행했다. 사용자 환경과 site 패키지를 배제하고 바이트코드 생성을 끈 상태에서, 감사 훅으로 소켓·프로세스 실행·파일 쓰기를 차단했다. 데모·테스트 모두 종료 코드 0이며 기대 출력이 같았다. 운영 DB·API·LLM·판매처 요청은 실행하지 않았다.

함수 6개의 원문 일치, 공통 게이트 파일의 바이트 일치, 명시적 공개 목록과 실제 파일 집합 일치, 로컬 문서 링크와 이미지 참조, 이미지 형식·메타데이터, 숨김 파일·심볼릭 링크·생성물 및 민감정보 패턴을 검사했다. 검토한 범위에서 제외 대상은 발견되지 않았다. 자동 패턴 검사는 누락 가능성이 있으며 완전한 공개 안전성을 보장하지 않는다.

## 아직 확인하지 않은 것

현재 앱 링크의 실기기 실행과 출시 상태, 현재 UI 캡처, 추출 구현의 현재 운영 반영, 전체 수집부터 앱까지의 통합 실행, 실제 사용자 수·구매 전환·오류 감소율은 확인하지 않았다. 초안 검증 당시에는 로컬 공개 후보로 검토했으며, 원격 저장소·PR·배포를 만들지 않았다.

## README 개편 확인
