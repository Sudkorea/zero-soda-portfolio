# 공개 예제의 검증 범위

## v1에 기록된 실행 결과

2026-09-17 공개본 초안의 기록입니다. README의 두 명령으로 합성 시나리오 8개의 출력이 `expected.json`과 일치했고, `unittest` 검사 메서드 4개가 통과했습니다. 아래 개수는 검사 범위이지 제품 성과나 전체 프로젝트의 테스트 수가 아닙니다.

| 입력 상황 | 가격 증거 검사 결과 |
|---|---|
| 완전한 표: A 12,000+3,000원, B 16,000+0원 | A·B 모두 통과; 순위 선택은 후속 경로 |
| A 합계 15,000원, 미확인 B 상품가 16,000원 | A만 통과 |
| 미확인 B 하한 15,000원 | 통과 없음 |
| 미확인 B 하한 14,000원 | 통과 없음 |
| 정확한 조건부 배송 표식 | 조건부 행 보존, A만 통과 |
| 표식이 소문자 `y` | 통과 없음 |
| 같은 판매처·옵션의 가격 충돌 | 통과 없음 |
| 상품가+배송비와 보고 합계 불일치 | 통과 없음 |

추가 검사는 배송비 누락·음수, 상품가 0, 금액 불일치, 판매처명 없음, 다른 출처, 목적지 불일치, 깨진 증거 금액, 충돌 표식, 별도 미확인 행, 빈 표와 중복 행을 다룹니다.

초기 검증 기록에는 공개 파일만 임시 디렉터리로 복사한 별도 Python 실행, 소켓·프로세스·파일 쓰기를 제한한 실행, 원본 함수·파일 대조, 공개 파일 목록·로컬 참조·이미지·민감정보 패턴 검사가 포함돼 있습니다. 이는 당시 공개 예제에 대한 기록이며 현재 운영 환경의 정상성이나 완전한 공개 안전성을 보장하지 않습니다.
